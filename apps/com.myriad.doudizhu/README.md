# 斗地主

3 人 54 张牌斗地主 — **商业级贴图牌桌**（绒毡 / 扑克 / 按钮 / 徽章纹理）。

## 功能

- **规则**：发牌 17/17/17 + 3 底牌，叫分 1–3，出牌/过牌
- **牌型**：单、对、三张、三带、顺子、连对、飞机、炸弹、王炸
- **贴图**：`assets/` 下绒毡桌面、场景、牌面/牌背、花色、按钮板、地主/农民徽章、座位框等（包体积 ≥ 2MiB）
- **提示**：合法出牌循环选择；无牌可压时引导过牌
- **反馈**：分座叫分/出牌/过牌、1–2 张报牌、终局摘要
- **联机**：`Tapp.federation` 房间 + host-seq 协议；亦可单机练习

## 资源

- 静态图在 `assets/`，于 `manifest.assets` 声明
- 运行时 `Tapp.assets.getUrl` 注入 `--ddz-tex-*` CSS 变量；无 API 时回退相对路径
- 资源为**原创程序生成纹理**，非第三方版权素材
