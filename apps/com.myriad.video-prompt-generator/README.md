# AI 视频提示词生成器

智能生成 AI 视频制作提示词，支持多种风格和场景。

## 功能特性

- 🎬 **多风格支持**：电影、动漫、写实、抽象艺术、3D 渲染
- 📐 **灵活参数**：可选择视频时长、画面比例
- 🤖 **AI 驱动**：使用 AI 自动生成结构化提示词
- 📋 **一键复制**：快速复制生成的提示词
- 📜 **历史记录**：保存最近生成的提示词供参考

## 生成的提示词结构

| 部分 | 说明 |
|------|------|
| **主提示词** | 详细描述视频内容、场景、主体、动作、情绪 |
| **镜头运动** | 摄影机移动方式，如推进、摇移、跟踪等 |
| **光影氛围** | 光线效果和整体氛围，如黄金时刻、戏剧光影 |
| **负面提示词** | 需要避免的元素，如模糊、变形、低质量 |

## 使用方法

1. 在输入框中描述你想要的视频内容
2. 选择视频风格、时长和画面比例
3. 点击"生成提示词"按钮
4. 复制生成的提示词到你使用的 AI 视频工具中

## 所需权限

| 权限 | 用途 |
|------|------|
| `storage` | 保存历史记录和设置 |
| `ui:notification` | 显示操作反馈 |
| `ui:theme` | 适配系统主题 |
| `ai:chat` | 调用 AI 生成提示词 |
