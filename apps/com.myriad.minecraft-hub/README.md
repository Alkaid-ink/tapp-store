# Minecraft 服务器与 Wiki

普通玩家可直接使用的 Minecraft 工具 Tapp。

作者：**我願一直向著陽光.℡**

## 功能

- 查询 Java 版与基岩版服务器
- 展示在线状态、MOTD、版本、人数、玩家、软件、IP 与端口
- 收藏服务器并保存最近查询
- 在 Tapp 内选择服务器，通过 4×2 首页小组件展示在线状态、人数、版本与 MOTD
- 搜索中文 Minecraft Wiki 并显示摘要
- 复制 Wiki 原文地址
- 支持深色模式与移动端

## 首页小组件

1. 进入 Tapp 的“我的服务器”页面，在“首页小组件设置”中填写 Java 版或基岩版服务器；也可以先查询服务器。
2. 点击“保存展示服务器”；查询成功后的结果卡片也提供“设为首页展示”快捷按钮。
3. 返回 Myriad 首页，添加“Minecraft 服务器状态”小组件。

小组件每 5 分钟刷新一次，并在重新显示时更新。尚未选择服务器时，小组件会提示先进入 Tapp 设置。

服务器状态由 mcsrvstat.us v3 提供，结果可能缓存约 5 分钟。Wiki 内容来自社区维护的中文 Minecraft Wiki。本插件与 Mojang Studios、Microsoft、Minecraft Wiki 及查询 API 服务方均无隶属关系。
