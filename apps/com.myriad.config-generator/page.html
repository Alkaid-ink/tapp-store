Myriad 安装配置生成

proxy + updater 单运行槽 · Docker Compose / .env / Nginx

ℹ️
这是什么？ 本工具帮你生成自托管 Myriad 首次部署所需的配置文件（不是改已有站点设置）。
产出：docker-compose.yml（启动服务）、.env（密钥与版本）、外层 Nginx、部署说明。

当前生产架构（先了解再填） 只有 proxy 对宿主机开端口；backend / frontend / 数据库 / updater 都在 Docker 内网。
升级是单运行槽 + 维护模式：先停业务、快照 ./pgdata、再换镜像版本；不是两套系统同时跑。
外层 HTTPS（宝塔 / 1Panel / Caddy 等）必须反代到 HTTP_PORT，不要直连 backend:1103。

🌐 域名配置

告诉 Myriad「用户从哪个网址访问你」。会写入 CORS（允许哪些网站调 API）、OAuth 回调、联邦公开地址，以及 Nginx 的 server_name。

用户浏览器地址栏里的域名，例如 myriad.example.com（一般不写 https://）。
会生成：BASE_URL / FRONTEND_URL / CORS_ORIGINS = https://你的域名。填错会导致登录回调、跨域或联邦地址错误。
若还要用 www. 或备用域名打开同一站点，填在这里。
作用：把该域名加入 CORS 白名单，并额外生成一份反代到同一 proxy 的 Nginx 配置。没有第二域名可留空。

🔐 安全配置

三项密钥都会写入 .env，启动时由 Docker 读入。页面打开时会自动生成；也可点右侧按钮重新生成或自行粘贴。 请妥善保存 .env，勿提交到 Git 或发给别人。

PostgreSQL 的登录密码，backend 连接数据库也用它。
要求 ≥32 字符；此处生成字母数字，避免特殊字符弄坏连接串。首次初始化后改密码较麻烦，建议用生成值并备份 .env。
用于签发/校验登录令牌（Cookie / JWT）。只有服务器知道这个密钥，别人才能伪造登录态。
要求 ≥32 字符（生成器默认 64）。若部署后改掉它，所有用户需要重新登录。
updater 服务的内部鉴权口令：backend 代替管理员调用升级 API 时使用。
浏览器和前端都不会看到它；正常升级走「管理员登录 → 关于 → 更新管理」。请勿贴到聊天/截图。救援直连时才可能手动用到。

🚀 版本与更新器

决定「第一次 docker compose up 拉哪些镜像版本」，以及以后 updater 从哪个发布通道检查更新。
镜像必须使用固定版本号（如 v0.0.2-rc.4），禁止 :latest——回滚依赖旧 tag 仍在仓库里。打开本页会从 Docker Hub 自动填最新 versioned tag。

正在获取最新版本…
业务镜像版本：backend + frontend 共用。日常「检查更新」主要会改这个。
入口代理镜像版本（对外路由、维护页）。改动少，通常与业务同步即可。
更新器自身版本（拉镜像、快照数据库、切 tag）。独立节奏，有时需先升 updater 再升业务。
updater「检查更新」时只看该通道的 GitHub Release。
stable = 正式；beta = 测试/rc；nightly = 最激进。若当前 tag 带 rc/beta，生成器会建议选 beta。
是否用 cosign 校验 release 签名，防止下到被篡改的升级包。
老 release 可能没有签名 → 用 off/soft；确认流水线已签过名后建议 strict。

🔧 服务配置

控制 Docker 在宿主机上暴露哪个端口，以及数据库镜像大版本。业务端口（1102/1103）在容器内固定，无需也不应映射到公网。

Myriad 在本机唯一对外开放的端口，默认 80。
外层 Nginx/Caddy 应反代到 127.0.0.1:这个端口。若 80 被占用，可改成 8080 等，并同步改反代配置。
数据目录在 ./pgdata（主机目录绑定，不是 Docker 匿名卷），以便 updater 做文件级快照回滚。
当前发布契约锁定 16；乱升大版本可能导致升级/回滚失败。
📌
内网端口（由镜像固定，不要改、不要映射到公网） frontend 1102 · backend 1103 · updater 1101 · postgres 5432
它们只在 Docker 网络里互通；对外只保留上面的 HTTP_PORT。

📊 资源限制

限制各容器最多能用多少 CPU / 内存，避免一台机器上某个服务吃光资源把整机拖死。
默认值对齐官方 compose，一般小规格 VPS 可直接用；内存紧张可适当调低，高负载再调高。

🗄️ PostgreSQL（数据库）

存用户与业务数据。一般最吃内存；过小会变慢，过大会挤占其他服务。

核心数，如 0.5 / 1.0 / 2.0

🎨 Frontend（前端静态站）

提供网页界面，负载通常低于 backend。默认 1 核 / 1G 足够多数场景。

核心数，如 0.25 / 0.5 / 1.0
如 256M / 512M / 1G

proxy（入口）与 updater（升级）与官方 compose 一致，默认不设 deploy 资源上限，避免升级拉镜像时被误杀。

📄 外层 Nginx（可选）

Myriad 自带的 proxy 只听 HTTP。公网 HTTPS 通常由外面一层 Nginx/Caddy/面板提供证书并反代进来。
本区用于生成或改写那一层配置：全部流量转到 127.0.0.1:HTTP_PORT。
